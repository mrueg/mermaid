Team Topologies Shapes

Colors match the official Team Topologies shape templates. Interaction mode nodes use 50% fill-opacity to convey their transient nature, per Team Topologies design guidelines.

Stream-aligned Team

flowchart LR
  classDef streamAligned fill:#FFEDB8,stroke:#FFD966,color:#000000
  A@{ shape: tt-stream, label: "Stream Team A" }
  B@{ shape: stream-aligned-team, label: "Stream Team B" }
  A --> B
  class A,B streamAligned

Full Team Topology Example

flowchart LR
  classDef streamAligned fill:#FFEDB8,stroke:#FFD966,color:#000000
  classDef enabling fill:#C9DFBE,stroke:#6AA84F,color:#000000
  classDef complicated fill:#FBDBBA,stroke:#F6B26B,color:#000000
  classDef platform fill:#BBD2F6,stroke:#6D9EEB,color:#000000
  classDef collaboration fill:#E3E0EE,stroke:#967EE2,color:#000000,fill-opacity:0.5
  classDef facilitation fill:#E3EFDE,stroke:#78996B,color:#000000,fill-opacity:0.5
  classDef xaas fill:#DAE8FC,stroke:#6C8EBF,color:#000000,fill-opacity:0.5

  sa1@{ shape: tt-stream, label: "Stream A" }
  sa2@{ shape: tt-stream, label: "Stream B" }
  en1@{ shape: tt-enabling, label: "Enabling Team" }
  cs1@{ shape: tt-complicated, label: "Complicated Subsystem" }
  pl1@{ shape: tt-platform, label: "Platform" }
  collab@{ shape: tt-collab, label: "Collaboration" }
  facil@{ shape: tt-facilitation, label: "Facilitation" }
  xaas@{ shape: tt-xaas, label: "X-as-a-Service" }

  pl1 --- sa1
  pl1 --- sa2
  en1 --- facil
  facil --- sa1
  cs1 --- collab
  collab --- sa2
  sa1 --- xaas
  xaas --- sa2

  class sa1,sa2 streamAligned
  class en1 enabling
  class cs1 complicated
  class pl1 platform
  class collab collaboration
  class facil facilitation
  class xaas xaas
